# 山河之旅（网页版儿童桌游）

《山河之旅》是一款适合 **2-4 人** 的中国地理启蒙桌游。本仓库提供：

- **前端**：单页面（`static/index.html`，样式与逻辑内联），使用 SVG 按**真实经纬度**绘制中国地图棋盘。
- **后端**：Python（`server.py` + `engine.py` + `map_data.py`），基于 Flask + Flask-SocketIO，
  负责房间管理（房间号 / 密码）、实时状态同步、回合超时自动行动。

## 游戏规则（官方游戏流程）

**步骤一**：每回合玩家投掷 **2 颗骰子**，根据骰子结果获得对应颜色的**旅行专用票（车票）**；
掷到 `GO` 面时，该票可作为**任意颜色**使用。

**步骤二**：玩家掷骰后进入**移动阶段，可以一步一步走**——每点一个高亮城市就走一段
（消耗该线路颜色的车票，界面上标注所需票数），**只要还有车票就可以继续点着走多步**；
也可以直接点 **结束回合** 不走。**结束这次移动后就不可再移动**。
（`GO` 票可顶替任意颜色；长途路线一段消耗 2 张同色票；未使用的车票**保留到下回合**。）

> 计分只发生在**移动结束（点结束回合或超时）时**：只有**最后停留的城市**能拿公共城市卡，
> 中途路过的城市不算；而**秘密目的地**在移动路径上"到达或经过"都算达成。

> **发牌设置**：每人共 **4 张牌** —— 桌面翻开 **①②③ 三张公共城市卡**（所有人可见，
> 是大家抢分的目标），外加 **④ 一张秘密城市卡**作为"最终目的地"（只有本人看得到，
> 别人只能看到一张背面 🎴）。合计 4 张。

**步骤三**：如果本回合**最后停留的城市**与桌面 **①②③** 公共卡中的任意一张相同，
该玩家收走这张卡，并获得卡上的分数（1-4 分）。

**步骤四**：取走城市卡后，翻开一张新的城市卡，保持桌面公共卡始终 3 张。

**胜利条件**：先攒够 **10 分**，并且 **到达或经过** 自己秘密的目标城市，就算胜利。
（因为一次移动可连续走多段，所以中途路过目的地也算达成。）

> 骰子六面为 **红/蓝/绿/黄/橙/GO**，因此路线颜色**只允许这 5 种**，
> 否则该颜色车票永远掷不出、路线无法通行（已在 `map_data.py` 中加入校验注释）。
> 注意区分：**公共城市卡只有"停在城市上"才得分**，但"秘密目的地"**经过即算达成**。

## 运行方式

```bash
pip install -r requirements.txt
python server.py
```

打开浏览器访问 `http://localhost:5000`：

1. 填写昵称，可选**自定义房间号**（4 位数字，留空则随机）、**房间密码**与回合超时，点击 **创建房间**。
2. 其他玩家填好昵称后，在大厅 **可加入的房间** 列表中**点击房间即可加入**；
   带 🔒 标记的房间会弹出密码框（回车或点"加入房间"提交）。
3. 房主可以点 **🤖 添加机器人** 凑人（支持人机对战，最多 4 人），
   机器人难度在创建房间时选择（普通 / 简单），凑齐至少 2 人后点击 **开始游戏**。
4. 轮到机器人时它会**自动掷骰、逐步移动并结束回合**，无需人工操作。

## 机器人 AI（`ai.py`）

- **目标评估**：桌面 3 张公共城市卡（分值越高越吸引）+ 自己的秘密目的地（权重最高，是获胜前提）。
- **路径规划**：启动时预计算全源最短段数（`ALL_DIST`），每步挑选"能缩短到目标距离且买得起"的城市。
- **踩点意识**：能一步踏上目标城市就立刻踩上去并停下——因为只有**最后停留的城市**才能拿卡。
- **不浪费票**：没有能缩短距离的走法时原地不动，把车票留到下回合。
- **难度**：`normal` 总是走最优；`easy` 有 35% 概率走随机一步，适合儿童。

> 提示：右上角徽章显示连接状态；大厅房间列表每 3 秒自动刷新。

## 目录结构

```
山河之旅/
├── server.py        # Flask + SocketIO 服务入口
├── engine.py        # 游戏引擎（房间/回合/掷骰/移动/得分/胜负）
├── ai.py            # 机器人 AI（目标评估 + 最短路径 + 踩点决策）
├── map_data.py      # 城市经纬度与得分、中国轮廓、路线、颜色、骰子面
├── requirements.txt
├── static/
│   └── index.html   # 单页面（含内联样式、逻辑与 Socket.IO 客户端）
└── README.md
```

## 说明

- 后端通过 WebSocket 实时同步；断线后凭本地存储的凭证可一键 **回到游戏**。
- 回合超时（默认 30 秒）由服务器定时器强制自动行动，避免卡局。
- 地图为简化示意坐标，非精确地理投影，仅用于儿童游戏与地理认知。
