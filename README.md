# 儿童棋牌大厅（网页版）

一个入口托管多款儿童棋牌。目前内置：

| 棋种 | 分类 | 棋盘 | 视图 | 规则 |
|---|---|---|---|---|
| 🏔 山河之旅 | 棋类 | 中国，51 城 / 77 线 | 平面地图 | 严格对齐正版 |
| 🌍 世界之旅 | 棋类 | 全球，66 城 / 83 线 | **平面地图 + 可旋转球面** | 开放（可调目标分、步数） |

- **前端**：大厅页 + 共用的游戏客户端（SVG 平面地图 / Canvas 球面地球），Socket.IO 客户端内联，无外网依赖。
- **后端**：Python（Flask + Flask-SocketIO），引擎与 AI 与具体棋盘解耦，**新增一款棋只需写一份 `map_data.py`**。

## 运行方式

```bash
pip install -r requirements.txt
python server.py
```

打开 `http://localhost:5000`：大厅按分类（棋类 / 牌类 …）列出棋种，点「开始游戏」进入 `/g/<棋种>/`。

## 游戏规则

**步骤一**：每回合掷 **2 颗骰子**，按颜色领取旅行票；掷到 `GO` 面可作**任意颜色**使用。

**步骤二**：沿线路移动，**每回合走 1 条线路**（正版规则），消耗该线路颜色的车票。
（`GO` 票可顶替任意颜色；长途线路消耗 2-3 张同色票；未用完的车票保留到下回合。）
《世界之旅》可把每回合步数调整为 1-3 步（创建房间时选择）。

**步骤三**：本回合**最后停留的城市**若与桌面 3 张公共城市卡之一相同，就拿走该卡得分（1-4 分），
并立即翻开一张新卡补足 3 张。**途经的城市不算**。

**胜利条件**：分数达标（默认 10 分，世界之旅可选 10/15/20）**且当前停在**自己的秘密目的地上，
立即获胜。秘密目的地同样只看**停留**，途经不算。

> 骰子六面为 **红/蓝/绿/黄/紫/GO**，因此线路颜色只能是这 5 色，否则该色车票永远掷不出来。

**超时**：每个回合独立计时（默认 30 秒）。超时后自动掷骰，并在尚未移动时**自动走一步**，
实在无路可走才跳过回合——不会白白浪费一个回合。

## 球面视图（世界之旅）

点击棋盘右上角 **🌍 球面 / 🗺 平面** 按钮切换。

- 纯 **Canvas 2D 正交投影**实现，**不依赖 three.js / d3**：避免 CDN 拉不到时白屏，离线可用。
- 可**鼠标 / 手指拖拽旋转**（左右转经度、上下转纬度），**默认静止不自动旋转**；
  松手后仅保留一点惯性并迅速停下（静止时不做无谓重绘）。
- **滚轮缩放**（0.75x - 2.2x），双击复位。
- 立体感：星空背景（暗色主题）、大气光晕、边缘入射阴影与高光；
  陆地点阵/航线/城市按深度淡出并缩小，凸显球面弧度。
- 大陆用**点阵**渲染（按 `cos(lat)` 稀疏化，保证球面密度均匀），航线为**大圆弧**，
  并自动隐藏地球背面的城市、航线与陆地点。
- 初始视角自动对准出发城市（北京）；点击高亮城市即可移动。

## 目录结构

```
├── server.py              # 入口：大厅 + 注册所有棋种
├── app.py                 # 云平台 WSGI 入口（gunicorn app:app）
├── core/                  # 与具体棋盘无关的通用层
│   ├── gamemap.py         # 地图容器：城市/线路/轮廓 + 投影 + 邻接 + 数据自检
│   ├── journey.py         # 通用"旅游棋"引擎：房间/回合/掷骰/移动/得分/胜负
│   ├── ai.py              # 机器人 AI（目标评估 + 最短路 + 踩点决策）
│   ├── net.py             # 网络层：按棋种注册 HTTP 接口与 Socket 命名空间
│   └── registry.py        # 棋种元信息（分类、图标、视图、可选规则）
├── games/                 # 一款棋一个目录
│   ├── shanhe/            # 山河之旅：map_data.py（棋盘数据）+ __init__.py（注册）
│   └── shijie/            # 世界之旅
├── static/
│   ├── lobby/index.html   # 大厅页
│   └── game.html          # 共用游戏客户端（平面 + 球面）
└── requirements.txt
```

## 新增一款棋

1. 建目录 `games/<id>/`，写 `map_data.py`：给出城市经纬度、分值、线路（颜色+票数）、陆地轮廓，
   并导出 `build_map()` 返回 `core.gamemap.GameMap`。
2. 写 `games/<id>/__init__.py`，用 `GameSpec(...)` 注册（分类、图标、说明、`views`、`options`）。
3. 在 `games/__init__.py` 的 `GAMES` 里加一行。

引擎、AI、房间、网络、前端全部复用；`GameMap.validate()` 可自检（孤城、重复线路、非法颜色等）。

## 机器人 AI（core/ai.py）

- **目标评估**：桌面 3 张公共城市卡（分值越高越吸引）+ 自己的秘密目的地（权重最高）。
- **路径规划**：预计算忽略颜色的全源最短段数，每步挑"能缩短距离且买得起"的城市。
- **踩点意识**：能一步踏上目标城市就立刻踩上去并停下（只有停留才算数）。
- **难度**：`normal` 走最优；`easy` 有 35% 概率随机一步，适合儿童。

## 说明

- 后端 WebSocket 实时同步；断线后凭本地凭证可一键 **回到游戏**。
- 支持主题切换（亮色 / 暗色），球面配色随之变化；视图选择会被记住。
- 地图为简化示意轮廓，非精确地理投影，仅用于儿童游戏与地理认知。
